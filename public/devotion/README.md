# Devotional side panels

Drop two images here and they appear automatically in the page margins
(left = Our Lady, right = St. Joseph). Until then, each margin shows a gold
arch motif instead, so nothing looks broken.

    mary.jpg      shown on the left
    joseph.jpg    shown on the right

Notes:

- **Portrait orientation** works best — the panels are tall and narrow
  (roughly 1:3). Anything wider gets center-cropped.
- Each image fades out toward the center of the page via a CSS mask, so a
  photo with its own background still blends in.
- Panels only render on wide screens (>=1280px); below that the schedule
  takes the full width.
- ~600px wide is plenty. Compress them — these are decorative and load on
  every page view.

## Where to get images you can actually use

These get served publicly, so use something you hold rights to:

1. **Photograph the Newman Center's own statues, icons, or stained glass.**
   Best option — it's yours, and it looks like your parish.
2. **Public-domain artwork.** Wikimedia Commons has many pre-1929 Marian and
   Josephite paintings marked public domain. Check each file's license.

Avoid pulling images off a general web search — most are still under
copyright even when they look old.
